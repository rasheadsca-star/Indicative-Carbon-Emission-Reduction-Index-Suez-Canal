# CERI-SC Intelligence Platform V6

**Indicative Carbon Emission Reduction Index — Suez Canal**

A bilingual, interactive decision-support dashboard for exploring the indicative emissions, fuel, distance, time, and economic effects of routing a single vessel through the Suez Canal versus the Cape of Good Hope.

## Live application

https://rasheadsca-star.github.io/Indicative-Carbon-Emission-Reduction-Index-Suez-Canal/

## Application modules

- Executive overview and dynamic indicators
- Complete single-vessel Suez vs Cape simulator
- Historical trend analysis (2015–2026)
- Alternative-fuel mix and emission factors
- Green projects, initiatives, and roadmap
- Manual data overrides, local saving, printing, PDF output, themes, Arabic and English

## Important notice

All results are indicative modelled estimates. They are not navigation advice, an official Suez Canal toll quotation, a certified MRV statement, a measured emissions inventory, or a carbon credit.

## Run locally

Open `index.html` in any modern browser. No installation or build step is required.

## GitHub Pages

The included workflow publishes the application automatically from the `main` branch using GitHub Pages.
