# تشغيل CERI-SC NEXT دون خادم أو نشر

**نسخة بحثية تجريبية بتاريخ 17 نوفمبر 2026.** لا تغير هذه الحزمة موقع هيئة قناة السويس ولا موقع GitHub Pages الحالي ولا الفرع main.

## التشغيل المباشر على Windows
1. نزّل ملف ZIP الخاص بالفرع التطويري:
   https://github.com/rasheadsca-star/Indicative-Carbon-Emission-Reduction-Index-Suez-Canal/archive/refs/heads/work/ceri-sc-voyage-integrity-20261116.zip
2. اختر **Extract All / استخراج الكل**، ولا تفتح HTML داخل برنامج ZIP.
3. افتح المجلد المستخرج، ثم **next/offline.html** بالنقر المزدوج في Chrome أو Edge.
4. لا يحتاج محرك الحسابات أو حفظ المدخلات أو جدول الحساسية إلى اتصال بالشبكة. الروابط المرجعية الخارجية تحتاج اتصالًا بالإنترنت؛ وقد تحتاج الصور المرفقة وبيانات سجل السفن إلى بقاء الملفات الأخرى في مجلد next.
5. «Save locally / حفظ محلي» يحفظ قيم المدخلات في متصفحك فقط؛ «Restore saved inputs / استعادة» يستعيد المدخلات ويعيد حساب النتائج. إذا فتحت الملف بعنوان مختلف أو حذفت بيانات المتصفح، فقد تختفي المدخلات المحفوظة.

## ما الذي يعمل؟
- مقارنة خمسة أزواج موانئ مستمدة من مسافات منشورة لهيئة قناة السويس، بما يشمل المسافة والوقت والوقود والـCO₂ الفيزيائي.
- حساسية هندسية: تغيّر السرعة ±2 عقدة والانتظار الإضافي في القناة 0/12/24 ساعة؛ الحالات غير الممكنة وفق قدرة MCR المدخلة تُحجب.
- حساب شرائح رسوم أساس SCNT المنشورة بدءًا من 15 يناير 2024 في SDR، ولا يمثل عرض سعر عبور لعام 2026.
- حساب اختياري لـWtW بمعامل أدخله المستخدم مع مسار إنتاج ومحرك ومصدر، دون ادعاء اعتماد مستقل.
- فحص أولي لنطاق EU ETS مع التمييز بين CO₂ والغازات الأخرى وFuelEU وIMO، دون اعتبار النتائج تكلفة امتثال نهائية.
- تصدير JSON للسيناريو من الواجهة.

## تحديث النسخة المحمولة
لا تعدّل offline.html يدويًا؛ هي نسخة مبنية آليًا من next/index.html والمحركات المصدرية الخمسة. بعد أي تعديل مصدر قم بتشغيل:
```bash
node scripts/build-offline.mjs --write
npm test
```
ويتحقق خط النشر آليًا باستخدام:
```bash
node scripts/build-offline.mjs --check
```

## الحدود
الإصدار الحالي ليس نظام MRV معتمدًا، ولا يثبت مواصفات محرك سفينة من رقم IMO، ولا يحتسب الرسوم النهائية للهيئة، ولا يؤكد توافر الوقود البديل أو سلامة مسارات الخرائط. نجاح الاختبارات الآلية لا يغني عن اختبار متصفح حقيقي ومراجعة هندسية مستقلة.
